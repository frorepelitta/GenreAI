# GenreAI — Классификация жанра фильма/книги по описанию

## Тема и цель проекта
- **Тема (A.5):** Классификация жанра книги/фильма по описанию.
- **Цель:** Создать веб-прототип интеллектуальной системы, которая по краткому текстовому описанию определяет наиболее вероятный жанр.

## Источник данных
- **Датасет:** Movie Genre Classification Dataset.
- **Признак (X):** текстовое описание сюжета.
- **Целевая переменная (y):** жанр произведения (`Genre`).
